# Implemented Features

This directory tracks feature behavior that is already implemented in the codebase.

## Contents

- `collector-descriptor-freshness-policy.md`
  Freshness and downgrade-protection policy for CollecTor server-descriptor-based
  Happy Families classification.
- `history-charts.md`
  Build-time bandwidth and uptime history charts on relay pages, and summed bandwidth on contact pages: PNG/SVG
  drawing, the chart cache, CLI options and CSS period switching.
- `tls-pqc-scan.md`
  Margot TLS cipher scan: CSV the scanner writes, HTML ahf.me publishes, and how
  absence from a scan is shown.

## Purpose

Use this directory for operational behavior docs that should match current code,
in contrast to `docs/features/planned/` which captures future proposals.
