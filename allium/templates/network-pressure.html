Tor's goal is more diverse relays and more trusted relays. More relays, run by more operators, spread risk and give end users a more anonymous, safer, and more secure network. Minimizing overloaded relays, maximizing the number of high-quality Guard and HSDir relays, and minimizing excessive directory requests keep that network safer.

{{ pressure_name('overload', 'Relays Reporting Overload') }} is the share of relays whose server descriptor that day includes an overload-general line (CollecTor server descriptors): a level, about a day late.

{{ pressure_name('guard', 'Relays with Guard Flag') }} is how many relays carry the Guard flag (Tor Metrics relay flags): a drop below the usual range confirms a problem that lasts for weeks.

{{ pressure_name('hsdir', 'Relays with HSDir Flag') }} is how many relays carry the HSDir flag (Tor Metrics relay flags), and the line turns red outside the usual range. The note under the title counts days in May 2025–May 2026 that moved more than 10% from the median of up to 28 earlier readings.

{{ pressure_name('directory', 'Directory Bytes Served') }} is the bytes relays sent while answering directory requests (Tor Metrics dirwrite): a rise above the usual range is a directory flood.

The 1 month, 6 months, 1 year, and 5 years buttons set every chart you have not changed yourself, and a chart's own thumbnails change only that chart. Days missing from Tor Metrics, and incomplete days, are left as gaps.

How the usual range is set

Each range is the 10th to 90th percentile of daily values from 1 May 2025 through 31 May 2026. It is saved once and does not move as new days arrive.

{{ pressure_name('overload', 'Relays Reporting Overload') }}. Each day is the share of relays that published a finished descriptor with an overload-general line. Green is that percentile range. Orange runs from its top up to 10%, and red is everything above 10%.

{{ pressure_name('guard', 'Relays with Guard Flag') }}. Each day is how many relays carried the Guard flag, skipping days that did not finish reporting flags. Green is the percentile range. Red is a day below the low end or above the high end.

{{ pressure_name('hsdir', 'Relays with HSDir Flag') }}. Each day is how many relays carried the HSDir flag, with the same skipped days and the same percentile range. Red is a day outside that range.

{{ pressure_name('directory', 'Directory Bytes Served') }}. Each day is the bytes relays sent while answering directory requests, in Gbit/s. Green is the percentile range. Red is only a day above the high end.
