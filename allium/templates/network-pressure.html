Tor's goal is more diverse relays and more trusted relays. More relays, run by more operators, spread risk and give end users a more anonymous, safer, and more secure network. Minimizing overloaded relays, maximizing the number of high-quality Guard and HSDir relays, and minimizing excessive directory requests keep that network safer.

Relays reporting overload is the share of relays whose server descriptor that day includes an overload-general line (CollecTor server descriptors): a level, about a day late, that measures pressure rather than a cause.

Relays with Guard Flag is how many relays carry the Guard flag (Tor Metrics relay flags): a drop below the usual range confirms a problem that lasts for weeks.

Relays with HSDir Flag is how many relays carry the HSDir flag (Tor Metrics relay flags), and the line turns red outside the usual range.

Directory bytes served is the bytes relays sent while answering directory requests (Tor Metrics dirwrite): a rise above the usual range is a directory flood.

The usual range is the 10th to 90th percentile for May 2025 through May 2026, frozen. The 1M, 6M, 1Y, and 5Y buttons set all four charts, and a chart's own thumbnails change only that chart. Days missing from Tor Metrics, and incomplete days, are left as gaps.
