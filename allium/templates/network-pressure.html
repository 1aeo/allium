Tor's goal is more diverse relays and more trusted relays. More relays, run by more operators, spread risk and give end users a more anonymous, safer, and more secure network. Minimizing overloaded relays, maximizing the number of high-quality Guard and HSDir relays, and minimizing excessive directory requests keep that network safer.

{% macro pressure_name(name, heading) -%} {%- if relays.pressure_periods.get(name) -%}{{ heading }}{%- else -%}{{ heading }}{%- endif -%} {%- endmacro %}

{{ pressure_name('overload', 'Relays Reporting Overload') }} is the share of relays whose server descriptor that day includes an overload-general line (CollecTor server descriptors): a level, about a day late.

{{ pressure_name('guard', 'Relays with Guard Flag') }} is how many relays carry the Guard flag (Tor Metrics relay flags): a drop below the usual range confirms a problem that lasts for weeks.

{{ pressure_name('hsdir', 'Relays with HSDir Flag') }} is how many relays carry the HSDir flag (Tor Metrics relay flags), and the line turns red outside the usual range. The note under the title counts days in May 2025–May 2026 that moved more than 10% from the previous 28 days.

{{ pressure_name('directory', 'Directory Bytes Served') }} is the bytes relays sent while answering directory requests (Tor Metrics dirwrite): a rise above the usual range is a directory flood.

The usual range is the 10th to 90th percentile for May 2025 through May 2026, frozen. The 1M, 6M, 1Y, and 5Y buttons set every chart you have not changed yourself, and a chart's own thumbnails change only that chart. Days missing from Tor Metrics, and incomplete days, are left as gaps.
